# Quarantined specs

These 18 specs are excluded from the default `npx playwright test` run via `testIgnore` in `playwright.config.ts`: 16 flat specs plus `example.spec.ts` (Playwright's own stock demo test against playwright.dev) hit the real Gemini API, the real Linear API, or the public internet with no mock, so they cannot pass offline; `simple-mode.spec.ts` mocks its `streamGenerateContent` network call correctly but was verified (Stage E) to never actually reach that mock with no `VITE_GEMINI_API_KEY` set — `@google/genai`'s client throws a synchronous "API key must be set" error before issuing any HTTP request, so `page.route` never gets a chance to intercept it, and per this stage's rule against introducing a dummy key, it stays quarantined rather than being forced green.
