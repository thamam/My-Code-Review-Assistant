# Archive

Everything under this directory (including `design_docs/`, moved here as a subtree) is **pre-simplification and unverified**: it was written against an earlier, differently-shaped tree — before the source-root consolidation and dead-code removal done in Stages A through D of the `programme/simplification` refactor — and none of its factual claims (module paths, model IDs, architecture diagrams, requirement counts, etc.) have been checked against the code as it stands today. Two of these documents (`ARCHITECTURE.md` and `TECH_BRIEF.md`) actively disagree with each other and with the current code in places (for example, `TECH_BRIEF.md` names a Gemini model ID, `gemini-3-pro-preview`, that does not exist anywhere in the current source).

`GEMINI.md` (Stage F) is archived here for the same reason: it names a stale phase/goal tracker, cites `docs/specs/` and `docs/architecture/` as the source of truth (both superseded by the root `ARCHITECTURE.md`), and names model IDs (`Gemini 3 Pro`, `Gemini 2.0 Flash`) that don't match any model ID in the current source (see `ARCHITECTURE.md`'s "Models in use" table). It was a third competing source of truth surviving untouched at the repo root; it is now consolidated here alongside the rest.

Nothing here was deleted — it's kept for history — but treat every claim in it as unverified until cross-checked against the code. The current, verified picture of the app lives in the repo root: `README.md` and `ARCHITECTURE.md`.
